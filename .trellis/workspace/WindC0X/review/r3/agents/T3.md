### [P2] T3-B4 `signal` 参数声明与实现不符（片 5 空转；片 1 真传导）
- 文件：`web/src/lib/canvas/registry-reader.ts:72`（声明）/ `:81`（解构）；`web/src/services/api/skills.ts:205-207`
- 证据：`LoadSkillPresetAssetsInput.signal?: AbortSignal`（注释「请求取消信号」）被解构出来，但函数体 `const payload = await listSkillPresets();` **不传 signal**；且 `listSkillPresets()` 本身不接受任何参数（`export function listSkillPresets() { return http.get<{presets: SkillPreset[]}>("/skills/presets"); }`）。对照片 1：`listTools({...}, { signal })` 是真传导。
