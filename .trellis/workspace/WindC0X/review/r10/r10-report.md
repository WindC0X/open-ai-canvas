## §5 A线 的异步 observer 边界补测 —— ✅ 我独立复现

### 5.1 A线 的声称

> 「异步 observer（queueMicrotask，真机语义）场景：修复健壮 ——
> `setTimeout(fn,0)` 是宏任务，`queueMicrotask` 是微任务 ⇒ 微任务先跑 ⇒ `splice` 总能命中自检记录」

### 5.2 我的独立复现（真机语义桩）

我构造了 **MutationObserver 回调走 `queueMicrotask`** 的桩（与浏览器语义一致）：
```
★ ok = true
★ msgLog = []
★ 残留? 无 ✓
```
**⇒ A线 的声称成立** ✓

### 5.3 机制核验

```
执行顺序：
  selfCheck() 内：
    document.body.appendChild(node)   → 触发 observer（微任务入队）
    return new Promise(resolve => setTimeout(fn, 0))   ← ★ 宏任务
  事件循环：
    微任务队列先执行 → observer 回调 → captureNode → msgLog.push(SELF_CHECK_TEXT)
    宏任务（setTimeout）后执行 → splice 移除 → ✓ 命中
```
**⇒ 机制正确**：微任务（observer）**总是先于**宏任务（`setTimeout`）执行 ✓

**★ 这是 R9 我未覆盖的场景** —— 我用的是**同步桩**（`appendChild` 直接调回调），
