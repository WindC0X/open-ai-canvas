# S1 空画布电商 starters（Agent 面板 starter 卡）

## Goal

Agent 面板新对话态（`AgentWelcome`）增补电商 starter 卡 3–5 张：点击 = 新命令（`3b3fe456` 自增 id prefill 语义）→ **立即发送执行**（点了就跑）；卡面常驻成本知情（相对档位）。对齐上游 `2088cf78` 创作入口结构，不另起炉灶、不碰上游结构（W6 同步零冲突）。

- 落点：`web/src/components/canvas/canvas-agent-welcome.tsx`（现三卡：选择技能 / 从灵感构思故事 / 一起梳理当前画布）；`onDraftPrompt` 目前仅 `setPrompt` 填充（`canvas-cloud-agent-panel.tsx:981/1393`）。
- prefill 命令通道：`project.tsx:314-315,547-548`（`agentPrefillIdRef.current += 1` + `setAgentPrefill({id,prompt})`）→ 面板 effect `canvas-cloud-agent-panel.tsx:277-283`（按 id 去重 → `setPrompt` + `setView("chat")`）。来源 commit `3b3fe456`（修"同命令被静默吞掉"）。

- 技能胶囊「广告电商」已存在（`canvas-cloud-agent-chat-ui.tsx:709`）——与 starter 卡不冲突（卡=提示词启动，胶囊=技能挂载）。

## Requirements

- R1 卡面：`AgentWelcome` 增补 4 张电商 starter 卡（现三卡保留，电商组置于其后）。卡 = 图标 + 标题 + 副标题（动作 + 成本档位，统一相对档位表述）。数量与文案见 §卡面草案（控制线 2026-09-27 已批）。
- R2 点击语义（裁决2-a）：必须走 `3b3fe456` prefill 通道——扩展命令为 `{id, prompt, submit?: true}`，不另造发送路径；点击 = 一条新命令立即执行；**同一张卡连点两次 = 两次都开跑**（id 自增，不被静默去重）。
- R3 运行中守卫（裁决2-b）：沿用现有 `busy/running` 守卫，不为 starter 卡另造队列；守卫拒绝时必须 toast「正在创作中，请稍候」，**禁止静默吞**；输入框保留已填入文案。
- R4 成本知情（裁决2-c，采纳方案一；方案三按成本可控叠加）：
  - 卡面副标题常驻预期消耗档位（相对档位，如「约 1 张图档」）；**任何价格数字禁止源码硬编码**（价格动态，遵循 09-26 渠道裁决），涉及数字必须运行时计算。
  - 可选叠加：余额低于预估时点击拦截提示；正常余额直接跑（若余额/预估链路成本可控则落，否则记录降级原因）。
  - 若默认模型解析到免费/低价通道（cpa-test 类）→ 卡面显示「免费体验」（运行时判定，不硬编码）。
  - 定性：信息层标注；首点轻确认弹窗（方案二）**不采用**。
- R5 防冲突：不改上游 `2088cf78` 入口结构与现有三卡行为；新增仅限卡片区 + 数据 + 接线。
