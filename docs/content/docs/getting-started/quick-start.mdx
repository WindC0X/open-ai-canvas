# 快速开始

这篇文档帮你在 10 分钟内跑通影策的核心链路：**注册 → 创建第一个节点 → 生成第一张图 → 和 Agent 一起创作**。

## 1. 注册并进入画布

打开影策站点，注册账号或直接登录。登录后进入工作台，打开一个**画布**即可开始创作。

## 2. 创建第一个节点

在画布底部工具栏点「**添加节点**」，选择要创建的内容类型（文本、图片、视频、音频、分镜脚本等）；也可以直接把素材文件拖进画布。

## 3. 生成第一张图

在图片节点的生成面板中：选择模型 → 填写提示词 → 确认比例与分辨率 → 点「**生成**」。任务完成后，结果会作为新的图片节点出现在画布上。

## 4. 和 Agent 一起创作

打开画布右下角的「**Agent**」面板，用自然语言描述你的目标（例如：把这几张素材整理成一个分镜流程）。Agent 会给出执行方案，需要确认的动作会先征求你的批准，完成后结果会落回画布。
