## 二、★ 一个意外发现（值得记档）

第一次提交时 `price_tier_id = T_DEFAULT`（通配档，100 microcredits），
**不是** `T_UPSCALE`。原因排查：

**我复制 DB 时，`T_UPSCALE` 的 `enabled=0`** —— 那是 step 0 探针**场景 B**
（故意禁用精确档以验证兜底行为）的遗留状态。探针后我在**探针环境**恢复了它，
但**复制动作发生在恢复之前**，所以 `.local/sr-verify` 拿到的是禁用态。

**⇒ 这次意外反而成了任务 1 价值的第二次实证**：
- 精确档禁用时：落 `T_DEFAULT`，价 100（静默）
- 精确档启用时：落 `T_UPSCALE`，价 777

修正后重跑，三段全通。
