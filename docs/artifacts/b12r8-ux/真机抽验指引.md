# 用户真机抽验指引（一页）

**被测版本**：`fc8337f9`（merge-v1.6.0 批树）｜**环境**：twin 栈 `:3400` / `:8482`
**抽验人**：产品用户（非测试）｜**预计耗时**：20-30 分钟

---

## 优先级 1：渠道可用性（**必查**，阻塞真实使用）

### ① 真实出图是否可用
- **步骤**：新建画布 → 添加图片节点 → 确认模型显示 `gpt-image-2 · ddcat-影策` → 输入 prompt → 点右下角 **`0.005` 那个按钮**（不是 `x1`）→ 等待
- **测试线实测**：`POST /api/tasks` 提交成功，但 **10.9s 后失败**：`模型服务鉴权失败，请检查 API Key 和模型权限`（`upstream_403`）
- **请确认**：**这是渠道 Key 失效（外部问题）还是产品配置问题？** 换其他渠道（a6api / Grok2Api）试是否可用？
- **同样问题存在于扩图**：图片工具 → 扩图 → 执行扩图 → 同样 `upstream_403`

> ⚠️ 若渠道 key 需更新，请更新后告知测试线，可立即重跑 R1/R2 验证真实图像链路。

## 优先级 2：小白困惑点（**建议查**，看是否真困惑）

### ② 首页 2 秒白屏
- **步骤**：清除登录态 → 访问首页 `http://127.0.0.1:3400/` → 观察前 2 秒
- **测试线实测**：**2000ms 内纯白无任何 loading 指示**，2s 后才出现内容
- **请确认**：真实网络下是否更久？是否值得加骨架屏？

### ③ 双击空白创建「绘图」节点
- **步骤**：空画布上**双击空白区域**
- **测试线实测**：**直接创建「绘图」节点**，无确认、无提示
- **请确认**：这是预期设计还是误触风险？新用户会困惑"节点哪来的"吗？

### ④ 模型选择器 L2 打不开
- **步骤**：图片节点 → 点 composer 上的 `gpt-image-2 · ddcat-影策` → L1 面板打开 → **hover 或点击 `ddcat-影策` 行**
- **测试线实测**：**L2（渠道内模型列表）三种方式均未展开**（L1 正常）
- **请确认**：真机鼠标 hover 能否展开？如不能 → 产品缺陷；如能 → 自动化限制（请告知，测试线补测）

### ⑤ 生成按钮 vs 份数下拉的误点
- **步骤**：填 prompt 后，注意 composer 右下角有**两个相邻按钮**：`x1`（生成份数）和 `0.005`（消耗积分，生成）
- **测试线实测**：我第一次点到了 `x1`，**下拉展开、无任何反馈、prompt 保留**，看起来像"提交没反应"
- **请确认**：误点后是否应给提示？两个按钮视觉区分度够吗？

## 优先级 3：体验细节（**可选查**）

### ⑥ Agent 撤销条跨会话消失
- **步骤**：Agent 建节点 → 撤销条出现 → **关闭画布、重新打开** → 撤销条还在吗？
- **测试线实测**：**不在了**（同会话内正常，nodes 1→0 成功）。DB mutation 仍 `applied`
- **请确认**：跨会话不需要撤销能力（设计如此）还是能力缺口？

### ⑦ 模型选择器中英混排
- **步骤**：打开模型选择器 L1
- **测试线实测**：`Pinned models` / `Providers` 是英文，空态「收藏的模型会显示在这里」是中文
- **请确认**：是否需要统一为中文？

### ⑧ 快捷键零发现性
- **步骤**：界面上找任何快捷键提示
- **测试线实测**：扫描全部 `[title]`/`[aria-label]` 得 **0 条快捷键提示**（帮助菜单内可能有，需主动打开）
- **请确认**：新用户是否需要 hover 提示或首启引导？
