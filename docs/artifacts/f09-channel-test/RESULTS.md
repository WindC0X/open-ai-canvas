## 4. 关键发现

### F1 · H1（构图沿用）假设成立 ✓

**证据**：设对 `size` 后，9 格 H1①② 全过（Δ 0.0%~5.1%）。
**反例修正**：首格（v2，未设 size ⇒ 1:1）Δ=17.5% 曾被误判为「模型不听话」——
实为**尺寸参数错误**。修正后 Δ 降至 0.2-2.6%。
⇒ **教训**：生成参数错误会伪装成模型失败（控制线要求登记）。

### F2 · 模板差异真实存在，机制为「指令内部矛盾」★

| 模板 | 标题匹配 | 判据判定 | 输出标题（读图逐字） |
|---|---|---|---|
| A（ImgAk 六段式） | **0.540** | REVIEW | `Navy Pleated Dress`（**改写** ✓） |
| B（libtv 四段式） | **0.830** | **FAIL** | `Floral Dress`（照抄 ✗） |
| C（Gemini 三句式） | **0.824** | **FAIL** | `Floral Dress`（照抄 ✗） |

**⇒ 判据与读图一致**：A 匹配值 0.540（低于阈值 0.55，REVIEW）vs B/C 0.830/0.824（远超阈值，FAIL）——
**阈值 0.55 清晰分开两个群体**（间隔 0.29）。

> ★ 数据修正记录：本表初稿的 A 值（0.838）来自**被顺序实验覆盖的文件**。
> 恢复原始文件（taskId `5c237bde8958`）后重跑，A 实际为 **0.540**。
> **这正是「记录必须绑定产物版本」的实例**（V7 附2 同族）。

**机制**（B/C 内部矛盾）：
```
B 句2：「保持产品外观、标签、文字完全不变」   ← 保持文字
B 句3：「不要沿用参考图中的…原有文案」        ← 不保持文字
⇒ 模型选择句2 ⇒ 照抄标题

A 无此矛盾：
  【2 优先级】显式给出冲突裁决顺序（元规则）
  【3 主体真实性】不含「文字」一词
  【4 原创与文字安全】独立成段 + 显式列举「旧广告文案」
```

**★ S2 场景（单图）无模板差异**：三模板均改写（无「产品图」⇒ 无冲突源）——
**这是对内部矛盾假设的独立支持**。

### F3 · 渠道能力边界：gpt-image-2.5 对含真实人物图片有内容政策限制

| 场景 | nano-banana-2 | gpt-image-2.5 |
|---|---|---|
| 含真实人物（S1 儿童模特） | ✓ 可用 | **✗ 内容政策拒绝** |
| 纯商品/海报（S2） | ✓ 可用 | ✓ 可用 |

**证据**：
- `api_call_logs.error_code = upstream_content_policy_reject`（原始错误，非用户可见消息）
- 对照实验：gpt-image-2.5 + 产品图（无人物，单图）→ **succeeded**
- S2（无人物）三格 → **succeeded**

**★ 精确表述**（证据支持的强度）：
> **S1（含真实儿童照片）在 gpt-image-2.5 上被内容政策拒绝。**
> **「图片数是否有贡献」未被排除**（缺「2图+无人物」对照格）——
> 但无论哪个变量触发，S1 在该渠道上均不可测 ⇒ **对 F-09 结论无影响**。
