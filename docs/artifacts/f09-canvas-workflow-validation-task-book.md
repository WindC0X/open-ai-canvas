## §3 验证步骤

### 步骤 1：搭画布（手工）

```
在画布上放置：
  ① 图片节点 A（命名「版式参考图」）—— 放一张爆款图
  ② 图片节点 B（命名「产品图」）—— 放一张产品图
  ③ Config 节点（生成节点）
  ④ 用 Frame 分组（可选）
  ⑤ 透明 PNG 引导层（可选，验证 Q3）

连线：A → Config，B → Config
```

### 步骤 2：写提示词（验证 Q1）—— ★ 本步骤有具体内容

**★ 重要前提**：二期注入层只负责**角色清单**（`输入图片角色清单：图1～N 是产品图…`），
**主体提示词必须由调用方（画布）写**。所以画布上要写的是「模板正文」。

#### 2.1 提示词的两部分

```
【A 角色清单】← 由后端 applyImageRolePrompt 自动注入（★ 画布上不用写）
  输入图片角色清单：
  共 2 张输入图。
  图1（产品图组）：只负责定义需要保真的替换商品；第一张为主角度。
  图2（版式参考图组）：定义视觉方案；第一张为主版式。
  严禁把产品图组与版式参考图组的角色互换。

【B 模板正文】← ★ 画布上要写这段
  （见下方 2.2 三种模板）
```

**★ 前提条件**：`config.productImageCount = 1`（否则注入层不生效，见 Q2）

#### 2.2 画布上要写的提示词（三选一，推荐 A）

**模板 A（ImgAk 六段式）—— ★ 一期实测 H3 通过率最高（A 格 10 次 9 次 PASS）**

```
【1 任务】根据"版式参考图组"制作一张原创商业视觉。用户替换主体图组定义需要保持真实并替换进成片的商品或主体；版式参考图组定义视觉方案，两组图片不得混淆，也不得因为替换商品而误删参考图中需要保留的人物。
【2 优先级】用户明确要求与准确文案 > 用户替换主体身份和事实 > 高度复刻的人物保留要求 > 逐张参考要求 > 选择的复刻策略 > 风格参考范围 > 模型自由发挥。冲突时按此前顺序执行。
【3 主体真实性】如提供主体图，必须保持可见类别、数量、轮廓比例、主色、材质、图案、Logo相对位置和结构部件；不要凭空增加功能、配件、认证、规格或卖点。看不清的细节要保守处理。
【4 原创与文字安全】不得照搬参考图中的品牌、Logo、水印、受保护角色、独特插画或旧广告文案。除用户准确文案或用户主体图中清晰可确认的内容外，不得生成价格、折扣、销量、排名、功效、证言、认证、参数或其他主体事实。
【5 输出要求】只生成一张完成度高的成片，不输出对比图、步骤图、网格草稿、解释文字或额外边框。
【6 动态段】用途要求：根据参考图制作电商商品图。
复刻策略：参考参考图的风格方向，允许适度自由发挥。
```

**模板 B（简版）—— ★ 一期实测会照抄文案（H3 失败率高），仅作对照**

```
参考图1（版式参考图）仅用于参考【构图/版式/光线/色彩】。
请以第二张图的产品为主体，保持产品外观、标签、文字完全不变。
不要沿用参考图中的品牌标识、logo、水印和原有文案。
输出【商品主图】比例。
复刻程度：参考风格。
```

**★ 模板 A vs B 的实测差异（一期渠道门）**：

| 模板 | 跑次 | H3 通过 | 读图真值 |
|---|---|---|---|
| **A（六段式）** | 10 | 9 | 改写标题 ✓ |
| **B（简版）** | 3 | 1 | 照抄标题 ✗ |
| C（英文） | 1 | 0 | 照抄 ✗ |

**⇒ 用模板 A。**

#### 2.3 画布上的写法（@提及 顺序）

```
在 Config 节点的 composer 里：

  @图片1 是产品图，@图片2 是版式参考图。
  （然后粘贴上面的模板 A 全文）

★ 或更简单（若 @提及 只用于定序，不参与提示词内容）：

  直接写模板 A 全文，然后用 @ 提及两张图定序：
  @[产品图节点] @[版式参考图节点]
```

**★ 关键：`@图片1` 必须指向「产品图」，`@图片2` 必须指向「版式参考图」** ——
因为后端按**数组位置**编号，数组顺序 = @提及顺序。

**★ 若顺序写反**：
```
referenceImages = [版式参考图, 产品图]
⇒ 后端注入：图1 = 版式参考图（错！应该是产品图）
⇒ 模型把版式参考图当产品图 ⇒ ★ 静默偏差，不报错
```

### 步骤 3：抓请求体（★ 关键证据）

```
在浏览器 DevTools Network 里抓生成请求，记录：
```

**★ 若 `referenceImages[0]` 是「产品图」⇒ 顺序正确；若是「版式参考图」⇒ 顺序反了**

### 步骤 4：真机生成

```
点生成 → 等待出图 → 检查：
  · 输出图是否保留了版式（H1）
  · 输出图的商品是否是产品图的商品（H2③）
  · 输出图的文案是否改写了（H3）
```

### 步骤 5：透明 PNG 引导层验证（Q3）

```
① 上传一张透明 PNG（画箭头/文字）
② 设置 metadata.locked = true
③ 截图，检查：
   · 工具栏是否隐藏
   · 视觉上是否像「画布标注」而非「一个节点」
   · 能否被误操作
```

**★ 若手工无法设置 locked，可用临时脚本改 DB/状态。**
